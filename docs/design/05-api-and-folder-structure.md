# 05. API Architecture & Folder Structure

## API conventions
- Base: `/api/v1`, JSON, OpenAPI auto-generated by FastAPI.
- Auth: OAuth2 password + refresh (JWT access 15 min, refresh 7 days, httpOnly cookie) ; optional Google SSO; TOTP MFA required for `founder`/`admin`.
- Tenancy: org resolved from token; every query filtered by `organization_id` (plus Postgres RLS).
- RBAC via dependency `require(permission)`; permissions matrix in doc 07.
- Pagination: cursor (`?cursor=&limit=`); filtering `?status=&priority=&owner=`.
- Idempotency: `Idempotency-Key` header on POSTs that trigger work.
- Errors: RFC 7807 problem+json.
- Real-time: `GET /api/v1/ws` WebSocket channels `tasks`, `approvals`, `activity` (Redis pub/sub).
- Webhooks in: `/api/v1/webhooks/{provider}` (signature verified) — n8n, Meta, WhatsApp, Shopify, Stripe/Razorpay.

## Endpoint map

| Area | Endpoints |
|---|---|
| Auth | `POST /auth/login` · `POST /auth/refresh` · `POST /auth/logout` · `POST /auth/mfa/verify` · `GET /me` |
| Organizations & users | `GET/PATCH /org` · `GET/POST /users` · `PATCH /users/{id}/role` |
| AI employees | `GET /employees` · `GET /employees/{id}` (workspace: tasks, deliverables, runs, KPIs) · `PATCH /employees/{id}` · `GET/POST /employees/{id}/instructions` · `POST /employees/{id}/instructions/{ver}/activate` |
| Manager | `POST /manager/instructions` (founder → Manager intake) · `POST /manager/plan/{project_id}` · `GET /manager/digest?date=` |
| Clients | CRUD `/clients` · `GET /clients/{id}/overview` · `POST /clients/{id}/onboarding` |
| Projects | CRUD `/projects` · `GET /projects/{id}/graph` (task DAG) |
| Tasks | CRUD `/tasks` · `POST /tasks/{id}/assign` · `POST /tasks/{id}/transition` `{to_status, note}` · `GET /tasks/{id}/runs` · `GET/POST /tasks/{id}/messages` · `POST /tasks/{id}/dependencies` · `POST /tasks/{id}/retry` |
| Deliverables | `GET /deliverables?task_id=&client_id=` · `GET /deliverables/{id}` · `POST /deliverables/{id}/versions` |
| Approvals | `GET /approvals?status=pending` · `GET /approvals/{id}` · `POST /approvals/{id}/approve` (MFA step-up for spend/financial) · `POST /approvals/{id}/reject` |
| Leads & contacts | CRUD `/leads` · `POST /leads/{id}/stage` · CRUD `/contacts` · `POST /contacts/{id}/dnc` |
| Campaigns | CRUD `/campaigns` · `GET /campaigns/{id}/metrics` |
| Content calendar | `GET /calendar?client_id=&from=&to=` · CRUD `/calendar/items` |
| Conversations | `GET /conversations` · `GET /conversations/{id}` · `POST /conversations/{id}/drafts` |
| Knowledge | `POST /kb/documents` (upload → chunk → embed job) · `GET /kb/search?q=&client_id=` |
| Integrations | `GET /integrations` · `POST /integrations/{provider}/connect` (OAuth start) · `GET /integrations/{provider}/callback` · `DELETE /integrations/{id}` |
| Models & costs | CRUD `/models` · `GET /usage?group_by=employee|model|day&from=&to=` |
| Reports & KPIs | `GET /dashboard/summary` · `GET /kpis?subject_type=&subject_id=&period=` · `GET /reports` · `POST /reports/generate` |
| Audit | `GET /activity?entity_type=&entity_id=&actor=` · `GET /activity/verify-chain` |

## Internal service boundaries (inside the FastAPI monolith)

```
api routers ─► services (business rules, state machine) ─► repositories (SQLAlchemy)
                    │
                    ├─► orchestration.dispatch(task) ─► Redis queue ─► worker
                    └─► approvals.request(...)  ◄── tool layer interceptor
```
